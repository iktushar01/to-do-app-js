# To-Do App (JavaScript)

A simple and lightweight To-Do application built with HTML, CSS, and vanilla JavaScript. This app allows users to add, complete, delete, and manage their tasks efficiently.

## 🌟 Features

- ✅ Add new tasks
- 📝 Edit existing tasks
- ✔️ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Stores tasks in localStorage
- 🎨 Simple and responsive UI
